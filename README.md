# AI-Powered Enterprise Workflow Platform

The capstone of the AI-agents track. Assemble everything into a real internal platform an enterprise runs for its own employees: a GraphQL gateway that exposes enterprise resources behind role-based permissions, a typed service layer over a Postgres system of record, a RAG knowledge service that grounds answers in enterprise docs, an LLM assistant that summarizes and drafts, a multi-step workflow engine with human-in-the-loop approval, a Redis-backed queue for async runs, a React + TypeScript chat and workflow dashboard, usage/reliability analytics with an audit log, and a Docker Compose stack plus an AWS deployment runbook. Optimized for scalable, governed, AI-powered employee productivity.

## Stack
- React
- TypeScript
- Node.js
- Python
- GraphQL
- PostgreSQL
- Redis
- AWS
- OpenAI API
